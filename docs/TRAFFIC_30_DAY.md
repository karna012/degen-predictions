# 30-day traffic checklist (Sports / Crypto / Stocks)

Assumption: mostly free / organic. Paid ads only after Search Console shows impressions.

## Weekly on-site snapshots (publish first, then share)

Create or update a short page / social post from live site data. Prefer linking to existing ranking and fixture URLs over long blog essays.

### Sports (primary)

- Lead with [MLB Today](https://degenpredictions.com/mlb/today) -- daily picks + live board.
- Post: top 3–5 confidence leans (winner + total runs), link each match page and `/mlb/results`.
- Also: weekend soccer top matches from `/sports/soccer` leagues.
- Once a week: link the Premier League backtest (`/premier_league/backtest`) and MLB ledger as “how we did.”

### Crypto

- Screenshot or list top 5 from `/crypto` (ticker + predicted 6-month return rank).
- One-line disclaimer: educational ML ranking, not investment advice.
- Link: `https://degenpredictions.com/crypto`

### Stocks

- Top 5 US from `/stocks/us` and/or top 5 India from `/stocks/india`.
- Same disclaimer; link to the market page.

## Distribution (Week 3+)

Value-first only -- no spam dumps of links.

| Channel | Angle |
|---------|--------|
| X / Twitter | Thread: 3 sports picks or 1 markets ranking table + single link |
| Telegram | Daily Top-3 + Best Combos slips (auto-post when bot creds set) |
| LinkedIn | Stocks ranking insight (US/India), professional tone |

Avoid Dubai ads, TikTok volume plays, and partnerships until the three-pillar positioning is live for 2+ weeks.

## Week-by-week

| Week | Do |
|------|----|
| 1 | Deploy focus UI; finish [SEARCH_CONSOLE.md](SEARCH_CONSOLE.md); request indexing on hub URLs |
| 2 | Publish 3 weekly snapshots (sports + crypto + stocks) on-site or as posts with deep links |
| 3 | Distribute the best-performing snapshot to 1–2 communities |
| 4 | Read Search Console + `/admin` analytics; double down on the pillar with impressions/clicks |

## Success signals

- Homepage/nav show only Sports / Crypto / Stocks
- Search Console property + sitemap Success
- Rising impressions on match or ranking queries
- At least one pillar clearly leading -- focus content there next month
